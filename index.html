元球液体

一堆模糊的球叠成一张浓度场，再用一条阈值线切出边界，切到的地方就是液体。 页面上的液体没有画过任何圆，也没有做碰撞——它只是这张浓度图的等值线。 右侧参数都可以拖，拖坏了点重置。

剖面曲线：一条横线上的浓度

在画面中线取一条横线，把它上面的浓度画成曲线。曲线高出虚线 T 的那几段就是液体，交点是液体的左右边界。

手感参数

预设

球太少，轮廓会被单个球带出疙瘩；球多了表面才连续。
调大更黏，容易成一大坨；调小更容易碎成小滴。
调大表面收紧、液滴易分离；调小整体膨胀、容易糊成一片。
调大边缘更软、融合更丝滑；调小边缘发硬，接近普通圆圈。
叠加时每个雾团中心有多浓。
调大更黏稠像蜂蜜，调小更弹像水银。

视图

先固定半径、只调阈值，最快找到顺眼的手感，剩下的都是微调。

画面里在算什么

每个球贡献一团浓度 exp(−3d²/R²)，把所有球加起来，得到一张没有边界的浓淡图。然后做一刀：smoothstep(T−soft, T+soft)，高于 T 的留下，低于 T 的抹成透明。

融合不需要额外逻辑。两滴靠近时，中间那块被两边同时抬高，越过 T，边界自己就连成一片；把阈值调高，同一张图又会裂成几滴。上面那条剖面曲线，画的就是这张图沿画面中线被切开的那一刀。

可以试的

  • 按住拖动：液体被推开、拉长，细的地方会自己在中间断开。
  • 点一下：在那个位置滴一滴，看它怎么被吸进去。
  • 雾团视图：关掉阈值，直接看那张浓淡图，青线标的就是刀口的位置。
  • 双色：颜色跟着球走，搅动后能看到两团把彼此的边界吞掉。
  • 重力：液体塌下去，在底部摊成一摊。

参数在动什么

参数实际改的是什么往两边拉会怎样
球的数量参与叠加的粒子数少：轮廓被单个球决定，出现疙瘩；多：表面连续，但更吃性能
球的半径 R高斯衰减的尺度大：容易连成一大坨；小：更易碎成小滴
阈值 T等值线的高度高：表面收紧、容易分离；低：整体膨胀、糊成一片
边缘模糊 softsmoothstep 的过渡宽度大：边缘软、融合丝滑；小：接近硬边圆，像两个球贴着
中心不透明度单个球的峰值浓度高：重叠区过饱和，融合处发白；低：叠加区分不足，看不出融合
速度阻尼速度的衰减率高：像蜂蜜；低：像水银

一般固定半径、只调阈值，最快找到顺眼的手感。

实现

一个片元着色器，全屏三角形，每个像素遍历所有球累加浓度，和阈值比一次就出结果。参数都是实时 uniform，拖滑块不会重编译。

// 每个像素的浓度：所有球相加
D = 0
for each ball b:
    D += center * exp( -3 * |p - b.pos|² / b.r² )

// 那一刀：soft 决定边缘多模糊
mask  = smoothstep( T - soft, T + soft, D )
color = mix( background, liquid, mask )

剖面曲线在 CPU 上用同一公式采样，所以曲线上的交点和画面里液体的边缘是对得上的。源码在 GitHub，单文件，无依赖。
