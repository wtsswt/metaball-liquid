# 元球液体 · 模糊 + 相加 + 一条阈值线

一个单文件的可交互讲解页：用「软膜 / 雾团 / 阈值刀」的直觉，讲清 metaball（元球）液体为什么能融合、为什么边缘必须模糊、参数该怎么调。

**在线页面**：https://wtsswt.github.io/metaball-liquid/

## 页面里有什么

- 实时 WebGL 元球液体，可拖动搅拌、点击加一滴
- 参数面板：球数 / 半径 / 阈值 / 边缘模糊 / 中心不透明度 / 速度阻尼 + 三组手感预设
- 「雾团视图」直接显示未做阈值处理的浓淡图，并用细线标出刀口位置
- 「双色」按浓度插值两种颜色，混合处自动出现第三种色
- 剖面曲线：沿画面中线采样浓度，画出曲线与阈值线的交点（液体左右边界）
- 文字部分：软膜比喻、两个「为什么」、逐帧流程、参数表、像液体不像软糖的三件事

## 实现

- 单个 `index.html`，无依赖、无构建
- 片元着色器每个像素累加所有球的 `center * exp(-3 * d² / R²)`，再做 `smoothstep(T - soft, T + soft, D)` 得到液体遮罩
- 剖面曲线在 CPU 上用同一公式采样，因此曲线交点与画面边缘一致
- 所有参数都是实时 uniform，拖动滑块不重编译着色器
- 响应式：`clamp()` 流式字号与间距，768 / 1024 断点，触摸目标 ≥ 44px
