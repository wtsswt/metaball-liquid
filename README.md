# 元球液体

WebGL 元球演示：模糊的球叠成一张浓度场，再用阈值线切出边界。没有画圆，也没有碰撞——液体的形状只是这张浓度图的等值线。

在线：<https://wtsswt.github.io/metaball-liquid/>

## 功能

- 拖动搅拌，点击滴一滴；拉得极细会在中段断开
- 六个参数：球数 / 半径 / 阈值 / 边缘模糊 / 中心不透明度 / 阻尼，另有清水、蜂蜜、果冻三组预设
- **雾团视图**：关掉阈值直接看未处理的浓淡图，青线标出刀口位置
- **双色**：颜色跟着粒子走，搅动时两团互相吞掉边界
- **重力**：液体塌下去摊成一摊
- **剖面曲线**：沿中线采样浓度，画出与阈值线的交点即液体左右边界

## 实现

片元着色器逐像素累加所有球的 `center * exp(-3 * d² / R²)`，再做 `smoothstep(T - soft, T + soft, D)` 得到液体遮罩。剖面曲线在 CPU 上用同一公式采样，因此曲线交点与画面边缘一致。所有参数都是实时 uniform，拖滑块不重编译着色器。
